# 🎥 TalkSpin – Random Video Chat App

TalkSpin is a cross-platform mobile application built with React Native that allows users to connect via **random 1-on-1 video calls** with people from around the world. Whether you're looking to meet new friends, pass the time, or have a spontaneous chat — TalkSpin makes it easy and fun.

---

## ✨ Features

- 🔄 **Random Matching** – Instantly connect with a random user
- 🎥 **Real-Time Video & Audio** – Smooth and high-quality video chat powered by WebRTC
- 🔐 **Secure Communication** – End-to-end encrypted signaling for safe and private connections
- 🌎 **Global Reach** – Meet people from different countries and cultures
- ⚡ **Lightweight & Fast** – Optimized for performance across Android and iOS devices
